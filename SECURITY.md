# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature for this repository. Do not open a public issue for an
unresolved vulnerability and do not include API keys, credentials, private
request bodies, or other secrets in a report.

The project is maintained on a best-effort basis. Reports will be acknowledged
as promptly as possible, but no response-time or remediation-time guarantee is
made.

## Supported versions

Until the project reaches `1.0.0`, security fixes are applied to the latest
code on the `main` branch. Older snapshots are not supported separately.
